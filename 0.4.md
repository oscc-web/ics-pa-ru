<!-- `vim` provides more improvements comparing with `vi`.

`vim` даёт больше улучшений по сравнению с `vi`.
Но эти улучшения по умолчанию выключены.
Поэтому сначала их нужно включить.

Возьмём подсветку синтаксиса как пример, чтобы показать, как включать возможности `vim`.

Сначала скопируем его в домашний каталог командой `cp`:
```
cp /etc/vim/vimrc ~/.vimrc
```
<!-- And switch to the home directory if you are not under it yet: -->

И перейдите в домашний каталог, если вы ещё не в нём:
```
cd ~
```

```diff
--- before modification
+++ after modification
@@ -21,3 +21,3 @@

+set background=dark
@@ -31,5 +31,5 @@

-"filetype plugin indent on
+filetype plugin indent on
@@ -37,10 +37,10 @@

 " differently from regular Vi. They are highly recommended though.
 "set showcmd            " Show (partial) command in status line.
-"set showmatch          " Show matching brackets.
-"set ignorecase         " Do case insensitive matching
-"set smartcase          " Do smart case matching

+set showmatch          " Show matching brackets.
+set ignorecase         " Do case insensitive matching
+set smartcase          " Do smart case matching
+set incsearch          " Incremental search
 "set autowrite          " Automatically save before commands like :next and :make
-"set hidden             " Hide buffers when they are abandoned
+set hidden             " Hide buffers when they are abandoned
 "set mouse=a            " Enable mouse usage (all modes)
```
