
<!-- ## Installing Tools -->

## Установка инструментов

<!-- In GNU/Linux, you can download and install a software by one command (which may be difficult to do in Windows).
This is achieved by the package manager.
Different GNU/Linux distribution has different package manager.
In Ubuntu, the package manager is called `apt`.

You will download and install some tools needed for the PAs from the network mirrors.
Before using the network mirrors, you should check whether the system can access the Internet. -->

В GNU/Linux вы можете скачать и установить программу одной командой (что в Windows может быть сложно).
Это обеспечивается менеджером пакетов.
У разных дистрибутивов GNU/Linux разные менеджеры пакетов.
В Ubuntu менеджер пакетов называется `apt`.

Вы скачаете и установите некоторые инструменты, нужные для PA, с сетевых зеркал.
Перед использованием сетевых зеркал проверьте, есть ли у системы доступ в интернет.

<!-- ### Checking network state -->

### Проверка состояния сети

<!-- Inside NJU, you should easily obtain an IPv6 address.
To test this, try to ping a mirror host with IPv6 support: -->

Внутри NJU вы должны без труда получить адрес IPv6.
Чтобы это проверить, попробуйте пропинговать хост зеркала с поддержкой IPv6:
```
ping mirrors.tuna.tsinghua.edu.cn -c 4
```

Вы должны успешно получить пакеты ответа:

<!-- If you do not have an IPv6 address, you may access the Internet by IPv4 address.

Если у вас нет адреса IPv6, вы можете выходить в интернет по адресу IPv4.
Можете попробовать пропинговать хост вне университетской LAN:
```
ping www.baidu.com -c 4
```
<!-- If you can ping Baidu successfully, you should successfully ping the mirror host above, too. -->

Если вы успешно пингуете Baidu, вы должны успешно пропинговать и хост зеркала выше.

<!-- ### Setting APT source file -->

### Настройка файла источников APT

<!-- > #### danger::If your system is not Ubuntu 22.04, please change to a suitable source
> Using a source that doesn't match your system will result in a conflicting version of the toolkit, and forcing the installation will damage your system.
> If you are using a system other than Ubuntu 22.04, please do not use the following sources, you need to search for appropriate sources and replace them. -->

> #### danger::Если ваша система не Ubuntu 22.04, смените источник на подходящий
> Использование источника, который не соответствует вашей системе, приведёт к конфликту версий набора инструментов, а принудительная установка повредит систему.
> Если вы используете систему, отличную от Ubuntu 22.04, не используйте следующие источники: вам нужно найти подходящие источники и заменить их.

<!-- Run the following commands to update the APT source file: -->

Выполните следующие команды, чтобы обновить файл источников APT:
```
bash -c 'echo "deb http://mirrors.aliyun.com/ubuntu/ jammy main restricted universe multiverse" > /etc/apt/sources.list'
```

<!-- However, you will receive an error message: -->

Однако вы получите сообщение об ошибке:
```
bash: /etc/apt/sources.list: Permission denied
```
<!-- This is because the APT source file is owned by root,
and you do not have the permission to modify it.

One solution is first switching to the root account.
But to avoid switching, an alternative way is to use `sudo`.
If you find an operation requires superuser permission, append `sudo` before that operation.
Before using `sudo`, you should add your account to the `sudo` group.
But first, you still need to switch to the root account. -->

Это потому, что файл источников APT принадлежит root,
и у вас нет права его изменять.

Одно решение — сначала переключиться на учётную запись root.
Но чтобы избежать переключения, альтернативный способ — использовать `sudo`.
Если операция требует прав суперпользователя, добавьте `sudo` перед этой операцией.
Перед использованием `sudo` нужно добавить вашу учётную запись в группу `sudo`.
Но сначала всё равно нужно переключиться на учётную запись root.
```bash
su -
Password:
```
<!-- Enter the root password you set during the installation.
Note that the password is not shown in the terminal to avoid password leaks.
If the password is correct, you will see the prompt changes: -->

Введите пароль root, который вы задали при установке.
Заметьте, что пароль не отображается в терминале, чтобы избежать утечки пароля.
Если пароль верный, вы увидите, что приглашение изменилось:
```bash
root@hostname:/home/username#
```
<!-- The last character is `#`, instead of `$` before you executing `su -`.
`#` is the indicator of root account.
Now you can add your account to the `sudo` group. -->

Последний символ — `#`, а не `$`, как до выполнения `su -`.
`#` — признак учётной записи root.
Теперь вы можете добавить свою учётную запись в группу `sudo`.
```bash
adduser username sudo  # Замените `username` на ваше имя пользователя
exit
```
<!-- To let the changes to take effect, you should log out or reboot.
After that, try -->

Чтобы изменения вступили в силу, выйдите из сеанса или перезагрузитесь.
После этого попробуйте
```bash
whoami
sudo whoami
```
<!-- If it is the first time you run `sudo`, enter the password of your account.
You should find that `sudo whoami` will output `root`.

Now you can use `sudo` to modify the APT source file.
This time you should modify it successfully.
To check this, you can output the file: -->

Если вы запускаете `sudo` впервые, введите пароль своей учётной записи.
Вы должны обнаружить, что `sudo whoami` выведет `root`.

Теперь вы можете использовать `sudo`, чтобы изменить файл источников APT.
На этот раз изменение должно пройти успешно.
Чтобы это проверить, можете вывести файл:
```
cat /etc/apt/sources.list
```
<!-- You should see it really outputs the line you just `echo`ed. -->

Вы должны увидеть, что он действительно выводит строку, которую вы только что передали в `echo`.

<!-- ### Updating APT package information -->

### Обновление информации о пакетах APT

<!-- Now you can tell `apt` to retrieve software information from the sources: -->

Теперь вы можете указать `apt` получить информацию о ПО из источников:
```
apt-get update
```
<!-- However, you will receive an error message: -->

Однако вы получите сообщение об ошибке:
```
E: Could not open lock file /var/lib/apt/lists/lock - open (13: Permission denied)
E: Unable to lock directory /var/lib/apt/lists/
```
<!-- This is because `apt-get` requires superuser privilege to run.
Run the command with superuser privilege.
Since it requires Internet accessing, it may cost some time to finish. -->

Это потому, что для запуска `apt-get` нужны права суперпользователя.
Выполните команду с правами суперпользователя.
Поскольку требуется доступ в интернет, это может занять некоторое время.

### Установка инструментов для PA

<!-- The following tools are necessary for PAs: -->

Следующие инструменты необходимы для PA:
```
apt-get install build-essential    # пакеты build-essential, включают binary utilities, gcc, make и так далее
apt-get install man                # онлайн-справочное руководство
apt-get install gcc-doc            # онлайн-справочное руководство для gcc
apt-get install gdb                # отладчик GNU
apt-get install git                # система контроля версий
apt-get install libreadline-dev    # библиотека, которая понадобится позже
apt-get install libsdl2-dev        # библиотека, которая понадобится позже
apt-get install llvm llvm-dev      # проект llvm, который содержит библиотеки, которые понадобятся позже
apt-get install llvm-11 llvm-11-dev # только для ubuntu20.04
```
<!-- The usage of these tools is explained later. -->

Использование этих инструментов объясняется позже.
